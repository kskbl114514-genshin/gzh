📦 JavaScript 数组方法 · 可视化

下方每个盒子代表数组里的一个元素，点击按钮实时看效果

当前数组 arr = [3, 7, 2, 9, 5, 7, 1]

一、增删方法（修改原数组）

push()

末尾追加一个元素，返回新长度
arr.push(10)

pop()

删除末尾元素，返回被删元素
arr.pop()

unshift()

开头插入元素，返回新长度
arr.unshift(0)

shift()

删除开头元素，返回被删元素
arr.shift()

splice()

万能增删：从下标2开始删2个，再插入 'a','b'
arr.splice(2, 2, 'a', 'b')

二、查询方法（不修改原数组）

indexOf()

找元素第一次出现的下标（7 出现两次）
arr.indexOf(7)

includes()

数组里是否包含某个值
arr.includes(9)

find()

找第一个满足条件的元素（偶数）
arr.find(n => n % 2 === 0)

filter()

筛选所有满足条件的元素（大于5）
arr.filter(n => n > 5)

三、变换方法（返回新数组，不改原数组）

map()

对每个元素做变换，返回新数组（×2）
arr.map(n => n * 2)

sort()

数字升序排序（必须传比较函数）
arr.sort((a,b) => a - b)

reverse()

翻转数组（⚠️ 会修改原数组）
arr.reverse()

slice()

截取 [1, 4) 范围，不修改原数组
arr.slice(1, 4)

四、迭代 / 归约方法

forEach()

遍历每个元素并执行回调，无返回值
arr.forEach((n,i) => console.log(i,n))

reduce()

累加求和（最强大的归约方法）
arr.reduce((a,b) => a + b, 0)

join()

用分隔符把数组拼成字符串
arr.join(" · ")

every() / some()

every: 是否全部满足   some: 是否有一个满足
arr.every(n => n > 0)  //全正?
arr.some(n => n > 8)   //有大于8?
