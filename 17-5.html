setTimeout vs setInterval

两种 JavaScript 定时器 · 区别 / 场景 / 交互演示

⏰ setTimeout 单次

setTimeout(fn, 2000) 表示"2 秒后执行一次 fn"，执行完毕自动结束，不会重复。

用 clearTimeout(id) 取消还没到点的定时器。

🔁 setInterval 重复

setInterval(fn, 1000) 表示"每 1 秒执行一次 fn"，永不停止直到主动取消。

用 clearInterval(id) 停止，否则会一直跑到页面关闭。

📖 清除函数 & 实战建议

// setTimeout → clearTimeout var st = setTimeout(function(){}, 3000); clearTimeout(st); // 还没到 3 秒就取消 // setInterval → clearInterval var it = setInterval(function(){}, 1000); clearInterval(it); // 永久停止

⚠️ 常见坑：
• setInterval 不会管上一次回调是否执行完毕，网络请求/重计算场景可能堆叠 → 用 setTimeout 递归 替代
• 页面切到后台时浏览器会把间隔拉大到至少 1 秒甚至 1 分钟 → 高精度场景用 requestAnimationFrame 或 Date.now() 差值
• 组件销毁/页面卸载时记得 clearInterval，否则会内存泄漏
