关键属性总结

实现 CSS3 3D 效果的核心属性。

perspective: 600px; /* 父元素定义透视深度 */ transform-style: preserve-3d; /* 子元素保留 3D 空间 */ backface-visibility: hidden; /* 隐藏背面 */ transform: rotateX(15deg) rotateY(-15deg) translateZ(20px); /* 动画 */ animation: name 3s ease infinite; /* GPU 加速 */ will-change: transform;
