Web 前端长度单位

CSS 中常用的长度单位一览 — 郭兹寒《高级网页设计》课堂练习

px 像素 绝对单位

屏幕显示的最小单位，1px 对应一个物理像素点。最常用的单位，精确控制元素尺寸。

示例：width: 200px; height: 60px;
200 × 60 px
width: 200px;
em 相对父元素 相对单位

相对于父元素的 font-size。若父元素字体为 16px，则 1em = 16px。常用于内边距、外边距的相对布局。

示例：width: 12em; height: 3em;（父元素 font-size: 16px）
12em × 3em
font-size: 16px;
width: 12em; /* = 192px */
rem 相对根元素 相对单位

相对于根元素（html）的 font-size。默认 1rem = 16px。避免了 em 的嵌套复合问题，推荐用于响应式布局。

示例：width: 12rem; height: 3rem;（根元素 font-size: 16px）
12rem × 3rem
html { font-size: 16px; }
width: 12rem; /* = 192px */
% 百分比 相对单位

相对于父元素对应属性的百分比。宽度相对于父元素宽度，字体大小相对于父元素 font-size。流式布局的核心单位。

示例：width: 80%; height: 60px;
80% 宽度
width: 80%;
vw 视口宽度 视口单位

Viewport Width，1vw = 视口宽度的 1%。随浏览器窗口宽度变化，适合全屏布局。

示例：width: 30vw; height: 60px;
30vw
width: 30vw; /* 视口宽度的30% */
vh 视口高度 视口单位

Viewport Height，1vh = 视口高度的 1%。随浏览器窗口高度变化，常用于全屏区块。

示例：width: 200px; height: 15vh;
15vh
height: 15vh; /* 视口高度的15% */
vmin 视口较小值 视口单位

取 vw 和 vh 中较小的一个。1vmin = 视口宽高中较小值的 1%。适合保持比例的正方形元素。

示例：width: 20vmin; height: 20vmin;
20vmin
width: 20vmin;
height: 20vmin;
vmax 视口较大值 视口单位

取 vw 和 vh 中较大的一个。1vmax = 视口宽高中较大值的 1%。

示例：width: 15vmax; height: 60px;
15vmax
width: 15vmax;
ch 字符宽度 相对单位

相对于当前字体中 "0" 字符的宽度。常用于限制文本列宽，提升可读性（理想行宽 45-75ch）。

示例：width: 30ch; height: 60px;
30ch
width: 30ch; /* 约30个字符宽 */
pt 点 绝对单位

印刷单位，1pt = 1/72 英寸。在屏幕上 1pt ≈ 1.333px。主要用于打印样式（@media print）。

示例：width: 150pt; height: 45pt;
150 × 45 pt
width: 150pt; /* ≈ 200px */

单位对比总结

单位 类型 参照基准 典型用途
px绝对物理像素边框、阴影、精确尺寸
em相对父元素 font-size内边距、外边距、组件级缩放
rem相对根元素 font-size字体大小、响应式间距
%相对父元素对应属性流式布局、宽度、高度
vw视口视口宽度 1%全屏布局、大标题
vh视口视口高度 1%全屏区块、垂直居中
vmin视口vw/vh 较小值 1%保持比例的正方形
vmax视口vw/vh 较大值 1%取较大视口维度
ch相对"0" 字符宽度文本列宽限制
pt绝对1/72 英寸打印样式
