💡 分层设计思想

从前端交互到知识库存储，六层逐层解耦。每一层都可以独立替换技术实现而不影响其他层。Agent 编排层是中枢，负责意图识别后路由到不同专家链路。

🔍 RAG 核心链路

Query → 改写 → Embedding → 向量检索 → BM25 混合 → Rerank 重排 → 上下文构建。HyDE、Decomposition、Step-back 等科研技巧已落地。

🧠 大模型技术栈

基座模型 + SFT/LoRA 指令调优 + DPO/RLHF 对齐 → 生成。Embedding 单独部署以支持动态向量维度。vLLM 提升推理吞吐。

📈 评测闭环

线上对话日志自动回流 → Golden QA Pair 扩充 → LLM-as-Judge 离线评测 → Faithfulness/Relevancy 指标 → 指导检索策略和 Prompt 调优。
