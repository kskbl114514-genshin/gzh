JavaScript 程序结构

条件结构与循环结构的基本用法，每个示例均在本页实时运行。

一、条件结构

1. if...else if...else —— 成绩等级判定

var gzh_score = 85; if (gzh_score >= 90) { '优秀'; } else if (gzh_score >= 80) { '良好'; } else if (gzh_score >= 60) { '及格'; } else { '不及格'; }

2. switch —— 星期几

var gzh_day = new Date().getDay(); switch (gzh_day) { case 0: '星期日'; break; case 1: '星期一'; break; /* ... case 2~5 ... */ case 6: '星期六'; break; }

3. 三元运算符 —— 奇偶判断

var gzh_n = 7; var gzh_r = (gzh_n % 2 === 0) ? '偶数' : '奇数';

二、循环结构

4. for 循环 —— 1 加到 100

var gzh_sum = 0; for (var gzh_i = 1; gzh_i <= 100; gzh_i++) { gzh_sum += gzh_i; }

5. while 循环 —— 累加首次超过 1000

var gzh_total = 0, gzh_k = 0; while (gzh_total <= 1000) { gzh_k++; gzh_total += gzh_k; }
