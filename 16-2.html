🏷️ JavaScript 对象 · 可视化

左边是当前对象的实时渲染，右边是可以执行的代码示例

当前对象 person = { name: "小明", age: 18, isStudent: true, hobby: "编程" }

一、创建对象的三种方式

对象字面量

最常用，花括号里写键值对
var person = {
  name: "小明",
  age: 18
};

new Object()

空对象，之后逐个添加属性
var p = new Object();
p.name = "小红";
p.age = 20;

构造函数

适合批量创建同类对象
function GzhUser(n, a) {
  this.name = n;
  this.age = a;
}
var u = new GzhUser("小刚", 22);

二、增删改查

读取属性

点号 . 和 方括号 [] 两种方式
person.name        // 点号
person["age"]      // 方括号

新增 / 修改属性

直接赋值即可，键不存在就新增
person.grade = 95;      // 新增
person.age = 19;        // 修改

删除属性 delete

用 delete 关键字删除某个属性
delete person.hobby;

检查属性是否存在 in

'属性名' in 对象 → true / false
'name' in person   // true
'email' in person   // false

三、遍历对象

for...in

遍历所有可枚举属性（包括原型链）
for (var k in person) {
  console.log(k, person[k]);
}

Object.keys()

返回所有键名组成的数组
Object.keys(person)
// ["name","age","isStudent","hobby"]

Object.values()

返回所有值组成的数组
Object.values(person)
// ["小明", 18, true, "编程"]

Object.entries()

返回 [键, 值] 二维数组
Object.entries(person)
// [["name","小明"],["age",18]...]

四、合并 / 拷贝 / 解构

Object.assign()

合并多个对象到第一个（浅拷贝）
Object.assign(person,
  { grade: 95 },
  { city: "北京" }
);

展开运算符合并

... 展开两个对象合并成新对象
var merged = {
  ...person,
  grade: 100,
  happy: true
};

解构赋值

从对象里把值"拆出来"赋给变量
var { name, age } = person;
console.log(name);  // 小明
console.log(age);   // 18

JSON 深拷贝

先序列化成字符串，再转回对象（不支持函数）
var copy = JSON.parse(
  JSON.stringify(person)
);
copy.name = "修改后";
// person.name 不变
