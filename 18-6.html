📊 流程图
使用 flowchart TD（从上到下），7 种自定义 classDef 配色区分网关 / Agent / RAG / LLM / 存储 / 评测 / 拒绝。虚线箭头表示离线评测闭环。
🗄️ ER 图
erDiagram 自动渲染实体矩形 + 关系线。PK / FK / 字段类型内置支持，一对多关系用 ||--o{，多对一用 }o--||。
🌊 Mermaid 10.x
本地离线 cdn/mermaid.min.js（~3.3 MB），无需外网。通过 mermaid.initialize({ startOnLoad: true }) 自动渲染页面上所有 .mermaid 块。
