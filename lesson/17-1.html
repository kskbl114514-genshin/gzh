什么是 JSON

JavaScript Object Notation · 轻量级数据交换格式

语法核心规则

① 键必须双引号"name": "小明"
② 值的类型字符串 / 数字 / 布尔 / null
③ 嵌套结构{} 对象   [] 数组
④ 无函数/undefined不允许出现 JS 特有类型

树形结构 · 点击折叠

两个核心方法

JSON.stringify() — 对象 → JSON 字符串
→
JSON.parse() — JSON 字符串 → 对象

JSON vs JS 对象对比

❌ 这不是 JSON（是 JS 对象）

{ name: "小明", // 键没加引号 age: 18, sayHi: function(){} // JSON 不允许函数 }

✅ 这才是合法的 JSON

{ "name": "小明", "age": 18, "score": null }
💡 JSON 只能表示 string、number、boolean、null、array、object 六种类型。函数、日期、undefined 等需要手动转换。
