JavaScript 基本数据类型

6 种 Primitive Data Types（基本 / 原始数据类型）

String · Number · Boolean · Null · Undefined · Symbol
1
字符串
String
typeof → "string"
由引号括起来的零个或多个字符序列，支持单引号、双引号和反引号（模板字符串）。
// 三种写法
var gzh_str1 = 'hello';
var gzh_str2 = "world";
var gzh_str3 = `郭兹寒 ${2026}`;
2
数字
Number
typeof → "number"
包括整数、浮点数、Infinity（无穷大）和 NaN（Not a Number）。只有浮点数这一种数值形式。
var gzh_int = 42;
var gzh_float = 3.14;
var gzh_sci = 1.5e3; // 科学计数法
var gzh_nan = NaN;
3
布尔值
Boolean
typeof → "boolean"
只有两个值：true（真）和 false（假）。常用于条件判断和比较运算的结果。
var gzh_isOk = true;
var gzh_isNo = false;
// 比较运算结果
var gzh_cmp = 10 > 5;
4
空值
Null
typeof null → "object" ⚠️
表示"空"或"无"，只有 null 这一个值。这是一个历史遗留 bug：typeof null 错误地返回 "object"。
var gzh_empty = null;
// 检查是否为 null 的正确方式
gzh_empty === null; // true
gzh_empty == undefined; // true（宽松相等）
5
未定义
Undefined
typeof → "undefined"
变量已声明但未赋值，或访问对象不存在的属性时，值就是 undefined。
var gzh_declared; // 声明但未赋值
var gzh_obj = { name: 'gzh' };
var gzh_missing = gzh_obj.age; // 不存在的属性
6
符号
Symbol
typeof → "symbol"
ES6 新增类型。每个 Symbol 都是唯一的，用作对象的唯一属性名，避免命名冲突。
var gzh_sym1 = Symbol();
var gzh_sym2 = Symbol('key');
gzh_sym1 === gzh_sym2; // false，永不相等
var gzh_obj2 = { [gzh_sym2]: 123 };
